# 月次更新の流れ(党勢指数v2)

毎月の記事を党勢指数v2で書くための手順と、Claudeに下書きを頼むときのプロンプトをまとめる。

## 自動で行われること

`systemd/` のタイマーで、次の2つが毎月自動で走る。PCが止まっていた場合は、次に起動したときに実行される。

| 日付 | 内容 | 所要時間 |
|---|---|---|
| 毎月5日 | 選挙結果キャッシュの更新クロール(`seiryoku.refresh_cli`) | 数時間 |
| 毎月7日 | 月次実行(`seiryoku.cli`)。v1とv2の計算、図、記事の事実データ | 10〜20分(推定し直す月はさらに10分ほど) |

月次実行の出力は次のとおり。

- `output/draft_facts_YYYY-MM.txt`: 記事の事実データ。「党勢指数v2」の節(各党の値・前月差・党勢を大きく動かした選挙)と政党支持率の節を使う
- `output/images/YYYY-MM/trend_v2.png`: 図1(党勢の推移、動きの内訳、首相の在任期間)
- `output/images/YYYY-MM/trend_v2_vs_support.png`: 政党支持率との散布図
- `output/images/YYYY-MM/trend_v2_by_party.png`: 政党別の図(補間の検証の×付き、毎月載せる必要はない)
- `output/trend/state_space_glm_YYYY-MM-DD.json`: v2の計算結果

## 毎月の手順

1. **月次実行の結果を確かめる。** `journalctl --user -u seiryoku-shisu.service` で終わったことと、画面の表示を見る。
   - 「[要確認] 略称表にない政党名」: `src/seiryoku/fetch/miharu.py` の `ABBREVIATIONS` に追加する(どの党か分からなければClaudeに調べてもらう)。
   - 「党勢指数v2: [失敗]」: Claudeに原因の調査を頼む。
   - 「[要対応] パラメータを推定し直しました」: 下の「国政選挙があったとき」の検証を回す。
2. **Claudeに記事の下書きを頼む。** 下のプロンプトを使う。
3. **下書きを確かめて公開する。** 下書きを直したら `PYTHONPATH=src python3 -m seiryoku.note_export notes/daiNkai_draft.md` で変換し、note用ファイルを貼る。画像はアップロードし、キャプション欄に「[キャプション: …]」の中身を入れる。note用ファイルを直接直した場合は、同じ修正を下書きにも入れる(変換し直すと消えるため)。
4. **公開版を照合する(任意)。** 公開URLをClaudeに渡して「公開版を照合して」と頼むと、本文と図表を手元のファイルと突き合わせる。
5. **コミットする。** Claudeが出すコマンドを実行する。

## 国政選挙があったとき

- 総務省の比例代表の得票率が公表されるまでは、月次実行は保存済みのパラメータを使う(画面に表示される)。公表後の月次実行で、自動的に推定し直す。
- 推定し直した月は、国政選挙を1回ずつ除いた補間の検証を手動で回す。ローカルの計算だけで、8コアで30分ほどかかる。

  ```
  PYTHONPATH=src python3 -m seiryoku.state_space_glm --validate --workers 8
  ```

- 新しい党の結成、合流、分裂があったら、系譜の対応表(`src/seiryoku/lineage.py` の `BRANCH_OF`、`ALLIANCE_MEMBERS`、`ALLIANCE_ORIGIN_SEATS`)の見直しをClaudeに頼む。合流した名義で戦った国政選挙の議席は、当選者の出身で元の党に分ける。

## 下書きを頼むプロンプト

YYYY-MMと第N回を書き換えて使う。

```
output/draft_facts_YYYY-MM.txt を読んで、第N回の記事の下書きを notes/daiNkai_draft.md に書いて。
- 指数は党勢指数v2を使う。事実データのv1の節(C_p、前月差の分解、重みシェア、前哨戦の検証、方向の目安)は使わない
- 構成と文体は notes/trend_v2_draft.md に合わせる(です・ます調)。v2の仕組みの説明は繰り返さず、v2を紹介した記事へのリンクで済ませる
- 毎月の必須の節:
  1. 選挙講評: その月の主な選挙の結果
  2. 党勢指数v2の更新: 各党の値と前月差の表(値の大きい順)。図1は output/images/YYYY-MM/trend_v2.png を notes/images/daiNkai_trend_v2.png にコピーして使う
  3. 党勢を動かした選挙: 事実データの「党勢を大きく動かしたもの」から、見込みと実際の差が大きかった選挙を挙げ、各党の前月差がどの選挙から来たかを説明する(勝因などの因果は書かない)
  4. 政党支持率: 事実データの全項目を三春さんの記事と同じ略称で表にし、更新日と出典リンクを添える。散布図は output/images/YYYY-MM/trend_v2_vs_support.png を notes/images/daiNkai_trend_v2_vs_support.png にコピーし、点線から大きく外れる党に触れる
- 図と表には毎回キャプションを付ける(直後の行に「*図1: …*」「*表1: …*」)
- 本文は5000字以内(note_exportで変換した後の文字数で確かめる)
- 事実データに警告(更新クロールの未完了、支持率の取得失敗、v2の計算の失敗、パラメータの推定し直し)があれば、書き始める前に知らせて
- 選挙講評で事実データにないこと(得票数、対立候補、推薦政党など)を書くときは、出典を調べて原文を示して
- 書き終えたら、重複・用語の初出・数値を見直してから note_export でnote用に変換し、コミットコマンドを出して
```
