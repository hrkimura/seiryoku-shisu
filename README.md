# 党勢指数

政党の党勢(政治的な勢い)の推移を、国会(衆参)・都道府県議会・市区町村議会の選挙と、知事・市区町村長の選挙から算出する非公式の定点観測プロジェクトです。メインの指数$C_p(T)$は、期間$T$(既定では直近12か月の後方スライディングウィンドウ)に実際にあった選挙だけを、その選挙が代表する人口(と、複数議席を同時に決める選挙は議席数)の平方根で加重して集計するフロー指標です。地方議会選挙は自民党系候補が党名を出さず無所属で出馬する慣行によるラベリングの非対称性があり、政党どうしの水準比較には使えません(この非対称性は届出政党をそのまま使う国会の扱いと同じにすることで許容しています)。そのため各政党自身の時系列推移として読む設計にしています(詳細は`design_document.tex`の§2.1・§2.6参照)。算出式・データソース・設計判断の詳細は [`design_document.tex`](design_document.tex) / [`design_document.pdf`](design_document.pdf) を参照してください。

## セットアップ

```bash
pip install -r requirements.txt
```

## 実行

```bash
PYTHONPATH=src python3 -m seiryoku.cli
```

市区町村ぶんの議席台帳(選挙ドットコム経由、1788自治体)は事前にクロール済みのキャッシュとして `data/municipal_registry.json` に同梱されているため、`git clone`直後の実行でも新たなクロールは発生しません。算出結果は `output/YYYY-MM-DD.json` に保存されます。

## 定期リフレッシュ(任意)

義務ではありませんが、`systemd/` 以下のunitファイルを使うと、データを定期的に新鮮に保てます。PCが常時起動していなくても、次回起動時に前回分を追いつき実行できます(`Persistent=true`)。

```bash
mkdir -p ~/.config/systemd/user
cp systemd/*.service systemd/*.timer ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now seiryoku-shisu.timer
```

## 構成

```
src/seiryoku/
  fetch/
    diet.py             # 衆議院・参議院の現在の会派別議席数
    diet_history.py     # 衆参の議席構成の推移(過去の月次再構成に使用)
    vote_share.py        # 衆院選小選挙区・参院選選挙区の得票率(政党要件の判定に使用)
    miharu.py             # 三春充希氏による各社世論調査の政党支持率の平均値(note記事の現在値)
    go2senkyo.py          # 選挙ドットコム: 首長・地方議会の選挙履歴
    jichisoken.py          # 地方自治総合研究所「全国首長名簿」: 首長の推薦・支持政党
    wikidata.py             # 選挙ドットコムで取得できない首長の補完
    population.py            # 都道府県・市区町村・全国の人口(令和2年国勢調査)
    seijiyama.py              # 知事議席台帳の差分更新(2025年10月頃から更新停止)
    local_parties.py           # 総務省: 地方議会・首長の党派別人員調の全国集計値(知事baseline等に使用)
    local_history.py            # 総務省の年次ページ(xlsx/xls)を遡った都道府県議会の党派別議席数の推移
    local_history_pdf.py         # 上記のうちPDFのみ配布の旧年度(平成18〜21年)ぶん
    budgets.py                    # 都道府県・市区町村決算カード(現在は重みの検証以外では未使用)
    codes.py                       # 市区町村コード改正履歴(合併の追跡)
    util.py                         # 共通のダウンロード・キャッシュユーティリティ
  lineage.py              # 政党名の名寄せ(改称・表記ゆれの吸収)とgit風の系譜イベント記録
  index.py                 # C_p(T)本体の算出、政党要件の判定
  monthly_index.py          # C_p(T)の月次フロー再構成(過去分・グラフ用)
  historical_index.py        # 月次再構成で使う衆参議席の日付スライス補助
  turnover.py                  # 党派転換指数 W_p^turnover(補助指標)
  registry.py                    # 知事の議席台帳(総務省baseline+政治山差分)
  municipal_registry.py           # 市区町村長・地方議会の議席台帳(選挙ドットコムベース)
  coverage_history.py              # 知事・市区町村のデータ網羅率(カバレッジ)を実行のたびに記録
  analysis.py                       # 補助的な集計・分析ユーティリティ
  support_history.py                 # 政党支持率S_p(t)の月次スナップショットの蓄積(追記方式)
  support_analysis.py                 # C_p(t)とS_p(t)の単位根検定・共和分検定・相関・ラグ相関
  cli.py                              # 月次実行のエントリポイント
```

## 現時点での既知の制約

- 政党要件(国会議員5人以上、または直近の国政選挙で得票率2%以上)の得票率判定は、衆院選小選挙区・参院選選挙区のみを見ています。総務省の比例代表サマリは議席を獲得した政党しか載らないため未対応です(`design_document.tex`の政党要件の節を参照)。
- 首長の推薦・支持政党による無所属の仕分けは実装済みです。公開されている年版(2018〜2025年の8年ぶん)を遡って合算し、知事47/47・市区町村長1718自治体ぶんを確認済みです。この情報源は年1回しか新版が出ないため、直近およそ半年〜1年の選挙はまだ判定できません(下限値として扱います)。
- 政党の合流・分裂時の実測配分は未実装です(`lineage.py`の`LINEAGE_EVENTS`に記録のみ)。
- 都道府県議会選挙は国会の選挙と同様、統一地方選のたびに一斉改選されるため、直近12か月ウィンドウの重みシェアが0%から最大30.8%まで跳ね上がる山型の挙動を示します(実測、design_document.texの§2.1参照)。これは意図した挙動であり、不具合ではありません。
- 党派転換指数$W_p^{\text{turnover}}(T)$は首長(知事・市区町村長)ぶんを実装済みです。議会(都道府県議会・市区町村議会)ぶんは未実装です。ただし直近12か月の窓は上記の推薦データ公開の遅れの影響を強く受け、実質的に中身のある値を出せないことが判明したため、ライブの現在値としては公開していません(`design_document.tex`の§2.7参照)。
- 政党支持率$S_p(t)$(三春充希氏の集計)は過去分がグラフ画像でしか公開されていないため、2026年10月から毎月の実行で現在値を1件ずつ積み上げています。取得に失敗した月は後から取り戻せません。単位根検定・共和分検定は24か月分、ラグ相関は30か月分たまるまで実行せず、結果は`data/support_analysis.json`に`insufficient`として記録されます。
- 財務省の予算シート名(`MOF_LATEST_SHEET`)は元号が変わるたびに手動更新が必要です。
